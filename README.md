# Kanban Board (Vue 3)

A simple Kanban board built with Vue 3 using the Composition API.

## Features

- Add / delete tasks  
- Rename tasks  
- Reorder tasks within a column (drag & drop)  
- Move tasks between columns (drag & drop)  
- 3 default columns: To Do / In Progress / Done  
- Tasks persistence with localStorage  
- Mobile-friendly UX (horizontal scroll for columns)  

## Tech Stack

- Vue 3  
- Composition API  
- JavaScript (ES6+)  
- CSS (scoped + global styles)  
- localStorage  
- [Vue Draggable / SortableJS](https://github.com/SortableJS/vue.draggable.next)  


## Project setup

```bash
pnpm install
pnpm run dev
```
